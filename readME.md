# Dungeon Crawler

A simple text-based RPG game developed in C.

## Features

-   Quality of Life
-   Save/Load
-   Map 10x20
-   Scens: 6 scen
-   Inventory: 3 types and 5 items for every type
-   Abilities: 5 different abilities
-   Explore the dungeon
-   Fight enemies and boss - the dragon

## Compilation

GCC and Make.

``` bash
mingw32-make
```

## Run

``` bash
./dungeon.exe
```

## Technologies

-   C
-   GCC
-   Make
